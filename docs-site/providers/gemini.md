# Gemini (BYOK)

Bring your own Google AI Studio API key to use Gemini models directly.

## Setup

1. Open **Settings** → enable the **Gemini** provider card
2. Click **Add/Update Key** — paste your API key from [Google AI Studio](https://aistudio.google.com/); stored in SecretStorage
3. Click **Test Connection** to confirm

## Model selection

The model picker is populated live from Google's Generative AI SDK.

## Token usage

Exact input/output counts come from the API's `usageMetadata` field.
